# neurofuzz — фаззинг с нейроэволюцией (NEAT)

Магистерский проект: «Применение нейроэволюционных алгоритмов для автоматизированного поиска
уязвимостей в программном обеспечении методом фаззинга».

**Идея.** Фаззер подаёт программе-цели (таргету) много изменённых входных данных и ищет такие,
на которых она падает. Обычный фаззер (AFL++) выбирает изменения (мутации) по фиксированным
правилам и случайно. Здесь мутации выбирает **нейросеть**: она видит, какие ветки кода прошёл
текущий вход (coverage bitmap) и сами байты входа, и говорит, какую мутацию сделать и где.
Сеть не обучается градиентами — её структура и веса **эволюционируют** алгоритмом NEAT:
сети, чьи мутации открывают больше нового кода и находят краши, дают потомство.

**Цель** — сравнить такой фаззер с AFL++ на одинаковых таргетах за одинаковое время.

## Что нужно

- Windows + PowerShell, Python 3.14 (`py`), пакеты: `neat-python matplotlib networkx pillow numpy`.
- Docker Desktop с образом `aflplusplus/aflplusplus:v4.21c`. Всё «тяжёлое» (компиляция таргетов,
  AFL++, запуск таргета) идёт внутри Docker; Python на Windows только управляет.

## Быстрый старт

```powershell
# 1. Эталон: AFL++ на 2.5 минуты
py -m neurofuzz.afl_baseline --target mini_maze --seconds 150

# 2. (один раз) собрать libpng из Magma
docker run --rm --security-opt seccomp=unconfined -v "D:\Projects\neat-fuzzer:/work" aflplusplus/aflplusplus:v4.21c bash /work/docker/build_libpng.sh

# 3. Проверить исполнитель на случайных мутациях
py -m neurofuzz.executor --target mini_maze --n 3000

# 4. Нейрофаззер (NEAT) на 5 минут
py -m neurofuzz.neat_fuzzer --target mini_maze --seconds 300

# 5. Сравнение AFL++ / NEAT / случайный фаззер — по 5 минут каждый, по очереди
py -m neurofuzz.compare --target mini_maze --seconds 300

# Работа с сохранённой моделью
py -m neurofuzz.model_tool run    --model results\<run>\neat\model --seconds 60
py -m neurofuzz.model_tool draw   --model results\<run>\neat\model
py -m neurofuzz.model_tool resume --checkpoint results\<run>\neat\checkpoints\neat-checkpoint-50 --seconds 120
py -m neurofuzz.model_tool gif    --run results\<run>
```

Таргеты: `mini_maze`, `mini_tlv` (мини-программы на C), `libpng` (Magma).

## Из чего состоит проект

| Часть | Что делает |
|---|---|
| `targets/mini/*.c` | Мини-таргеты с намеренно спрятанными багами. `mini_maze` — «лабиринт»: нужно угадать магию `NEAT` и команду; `mini_tlv` — парсер записей «тип-длина-значение». Сиды — в `targets/*/seeds/`. |
| `docker/build_mini.sh`, `docker/build_libpng.sh` | Сборка таргетов с инструментацией AFL++ внутри контейнера. libpng собирается с 7 багами Magma (PNG001–PNG007) и AddressSanitizer. |
| `neurofuzz/afl_baseline.py` | Эталон: запускает `afl-fuzz` в контейнере на N секунд и переводит его статистику в CSV. |
| `docker/afl_replay.py` | После AFL++ прогоняет всю его очередь через `afl-showmap`, чтобы посчитать покрытие по времени **той же метрикой**, что и у нейрофаззера. |
| `docker/executor_server.py` + `neurofuzz/executor.py` | Исполнитель: в контейнере постоянно работает сервер; Python отдаёт ему пачку входов, получает для каждого карту покрытия (какие рёбра кода пройдены) и статус (норма / таймаут / краш). |
| `neurofuzz/mutations.py` | 8 операторов мутаций: инвертировать бит, записать байт, вставить, удалить, «интересное» число, ±число, скопировать блок, склеить с другим входом. |
| `neurofuzz/tracker.py` | Учёт: общее покрытие, корпус интересных входов, уникальные краши, CSV «покрытие/краши от времени». |
| `neurofuzz/policy.py` | Как состояние превращается во входы сети (46 чисел) и как выходы сети (11 чисел) — в мутацию. |
| `neurofuzz/neat_fuzzer.py` | Нейрофаззер: цикл «поколение → оценка → отбор», fitness, чекпоинты, сохранение модели, кадры сети и GIF. |
| `configs/neat_config.ini` | Параметры NEAT (размер популяции, вероятности мутаций сети и т. д.). |
| `neurofuzz/random_fuzzer.py` | Контрольная группа: всё как у нейрофаззера, но мутации выбираются случайно. Показывает, что даёт именно нейросеть. |
| `neurofuzz/compare.py` | Сравнение: AFL++, NEAT и случайный фаззер по очереди, одинаковое время, сводная таблица и графики. |
| `neurofuzz/plots.py` | Графики SVG: покрытие и краши от времени, исполнения от времени, fitness по поколениям, сложность сети. |
| `neurofuzz/viz.py` | Схема сети NEAT (SVG/PNG) и сборка GIF эволюции сети. |
| `neurofuzz/model_tool.py` | Загрузить сохранённую модель: запустить на таргете, нарисовать, продолжить обучение, пересобрать GIF. |
| `neurofuzz/common.py` | Общее: папки запусков, логи, запуск Docker. |

### Как устроена сеть

- **Входы (46):** покрытие родительского входа, сжатое в 16 «корзин»; доля общего покрытия;
  «свежесть» родителя; первые 24 байта входа; длина; номер шага; 2 случайных числа
  (чтобы сеть могла вести себя не строго детерминированно).
- **Выходы (11):** 8 оценок операторов (выбирается максимальная), позиция, значение,
  сколько мутаций подряд сделать (1–8).
- **Fitness сети за поколение:** 10 × новые рёбра кода + 1 × новые счётчики попаданий +
  100 × новые уникальные краши + небольшие бонусы за разнообразие путей и входов.

## Куда пишутся результаты

Каждый запуск — своя пара папок с датой и временем (`<дата>_<время>_<вид>`), ничего не
перезаписывается:

```
results/2026-10-17_21-00-00_compare/
  comparison_summary.csv          сводка: финальное покрытие, краши, время до первого краша...
  plots/*.svg                     графики
  afl/afl_timeline.csv            покрытие/краши AFL++ по времени (+ raw/ — файлы AFL, краши)
  neat/neat_timeline.csv          то же для нейрофаззера
  neat/generations.csv            по поколениям: fitness, покрытие, виды, размер сети...
  neat/model/                     best_genome.pkl, neat_config.ini, model_info.json, best_genome.svg
  neat/checkpoints/               чекпоинты популяции NEAT + корпус (*.corpus.gz)
  neat/genomes/                   лучший геном каждого поколения
  neat/crashes/                   найденные краши
  network/frames/*.svg|png        схема лучшей сети по поколениям; network/evolution.gif
  random/...                      то же для случайного фаззера
logs/2026-10-17_21-00-00_compare/
  run.log         текстовый лог          errors.log   только ошибки/предупреждения
  events.jsonl    события (новое покрытие, новый краш, чекпоинт...)
  generations.jsonl  строка JSON на каждое поколение NEAT
  config.json     конфигурация запуска (+ версия кода = git-хэш)
```

Файлы `*.jsonl` удобно целиком отдавать в Claude Code для разбора: одна строка — одно событие.
