# Что не получилось / что осталось (TODO)

- **libpng: крашей за короткие прогоны нет.** Баги Magma PNG001..PNG007 требуют долгого фаззинга (часы). Для оценки «найденных багов» на libpng нужны длинные прогоны и/или канарейки Magma (MAGMA_ENABLE_CANARIES + чтение canaries.raw) — не сделано.

- **Один прогон на конфигурацию.** Для статистически значимых выводов нужно 5–10 повторов каждого фаззера с разными сидами и тест Манна–Уитни (стандарт Klees et al., 2018). `compare.py` пока делает один прогон; нужно добавить `--repeats` и усреднение с доверительными интервалами на графиках.
- **Короткие прогоны (минуты).** В литературе — 24 часа. Для libpng особенно: за минуты крашей нет ни у кого.
- **Пропускная способность нейрофаззера ниже AFL++** (~1000–2000 исп./с против 2–30 тыс./с): Python-цикл, пачки через afl-showmap вместо собственного forkserver/persistent-режима. Ускорение: свой forkserver-клиент или перенос сервера на C; persistent mode для libpng (сейчас afl-showmap в -i режиме, вероятно, перезапускает процесс на каждый вход).
- **Сеть видит только первые 24 байта** и 16 корзин покрытия. Для форматов вроде PNG (важные поля далеко от начала) нужно окно вокруг позиции, выбираемой сетью, или «внимание» по позициям.
- **Fitness нестационарен:** чем дальше, тем меньше нового покрытия найти, поэтому «лучший за всё время» геном — обычно из ранних поколений. Возможное улучшение: нормировать fitness на «сложность» поколения или использовать novelty search.
- **Канарейки Magma** (факт достижения/срабатывания бага без краша) не подключены.
